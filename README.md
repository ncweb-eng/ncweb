# NCWEB — Home modelo

Home recriada a partir do layout visual aprovado:
- hero tecnológico
- mapa/rede regional
- serviços
- cards de planos
- status da rede
- métricas
- responsividade mobile

Tecnologia: Next.js + TypeScript + CSS + Lucide.

## Instalação
npm install
npm run dev

## Produção
npm run build
npm start

## Integrações futuras
- SGP / Central do assinante
- Zabbix para Status da Rede
- WhatsApp oficial
- consulta de viabilidade
- mapa real da cobertura
